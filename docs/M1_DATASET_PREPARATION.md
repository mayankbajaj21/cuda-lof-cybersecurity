## 1. Overview & Objective
The objective of **Milestone M1** is to ingest, inspect, clean, standardize, and partition the **CICIDS2017** cybersecurity benchmark dataset into high-efficiency numerical arrays and controlled experimental subsets ready for downstream unsupervised anomaly detection (Local Outlier Factor) starting in **M2**.

## 3. Data Inspection & Cleaning

### 3.1 Cleaning Decisions
1. **Header Whitespace & Formatting**: Column headers in raw CICIDS2017 CSVs contain inconsistent leading and trailing whitespaces (e.g. `' Destination Port'`, `' Label'`). All headers were stripped and sanitized.
2. **Corrupted Unicode in Labels**: The Thursday morning Web Attacks file contained corrupted replacement characters (`\ufffd`) in label strings. These were normalized (e.g., `Web Attack - Brute Force`, `Web Attack - XSS`, `Web Attack - Sql Injection`).
3. **Invalid & Infinite Values**:
   - `1,358` rows contained `NaN` values (primarily in `Flow Bytes/s`).
   - `2,867` rows contained `+Inf` / `-Inf` values (in `Flow Bytes/s` and `Flow Packets/s`).
   - All `2,867` invalid rows were safely removed.
4. **Deduplication**: `308,381` duplicate network flow records across the files were removed to prevent artificial metric collapse in $k$-NN distance calculations.

### 3.2 Cleaning Summary
- **Initial Total Records**: `2,830,743`
- **Invalid Records Removed**: `2,867`
- **Duplicate Records Removed**: `308,381`
- **Final Cleaned Records**: **`2,520,798`** (89.05% retained)

## 6. Numerical Preprocessing & Scaling

### 6.1 StandardScaler (Z-Score Normalization)
Local Outlier Factor relies on Euclidean distance metrics $d(p, q) = \sqrt{\sum_{i=1}^D (p_i - q_i)^2}$.
Network traffic features span disparate orders of magnitude (e.g. `Flow Duration` up to $10^8\ \mu\text{s}$ vs `FIN Flag Count` in $\{0, 1\}$). Unscaled features would cause distance calculations to be overwhelmingly dominated by high-variance temporal columns.

Features are normalized via **StandardScaler**:
$$z = \frac{x - \mu}{\sigma}$$
Fitted over the reference cleaned dataset and exported to `dataset_metadata.json` for reproducible inference transformations.

### 6.2 Float32 Precision for GPU Acceleration
All feature matrices are cast to single-precision IEEE 754 float (`np.float32`). Float32 offers:
- Optimal single-precision floating point throughput on NVIDIA Turing/Ampere architectures.
- 50% memory reduction relative to `float64`, reducing bandwidth saturation in GPU VRAM transfers.
