# Preprocessing Pipeline: CICIDS2017

**Current Milestone**: `M1 — Dataset Preparation`

## 1. Purpose
The `preprocessing/` directory contains all authoritative Python modules responsible for dataset acquisition, raw CSV inspection, data cleaning, domain feature selection, target label separation, standardization, and reproducible subset generation for the **CICIDS2017** benchmark dataset.

The outputs generated by this pipeline are consumed by downstream Local Outlier Factor (LOF) anomaly detection milestones starting in **M2**.

---


## 3. Preprocessing Workflow

### 3.1 Dataset Acquisition (`download_dataset.py`)
- Documents official public sources from the Canadian Institute for Cybersecurity (UNB): [CICIDS2017](https://www.unb.ca/cic/datasets/ids-2017.html).
- Verifies local presence of all 8 raw CSV files in `data/raw/` representing 5 days of captured network flows.

### 3.2 Dataset Inspection (`inspect_dataset.py`)
- Inspects all raw CSV files to detect column name whitespace issues, total row counts, data types, missing (`NaN`) values, infinite (`+Inf`, `-Inf`) values, duplicate rows, and class distributions.

### 3.3 Data Cleaning & Hygiene
- **Header Sanitization**: Strips leading and trailing whitespaces from all raw column names.
- **Corrupted Characters**: Cleans replacement characters (`\ufffd`) in label strings.
- **NaN / Infinite Values**: Removes invalid records (1,358 rows containing `NaN` and 2,867 rows containing `+Inf`/`-Inf` in flow throughput metrics).
- **Duplicate Removal**: Eliminates 308,381 duplicate network flows to prevent zero-distance metric collapse in $k$-NN density calculations.

### 3.4 Feature Selection & Domain Exclusions
From 79 original columns, **68 numerical features** are retained. **11 columns are excluded** based on domain and mathematical rationale:
- `Label`: Separated from features to avoid data leakage.
- `Destination Port`: Network port identifier; discrete port numbers introduce artificial metric bias.
- `Fwd Header Length.1`: Exact duplicate of `Fwd Header Length` from CICFlowMeter generation bug.
- 8 Zero-Variance Columns (`Bwd PSH Flags`, `Bwd URG Flags`, `Fwd Avg Bytes/Bulk`, `Fwd Avg Packets/Bulk`, `Fwd Avg Bulk Rate`, `Bwd Avg Bytes/Bulk`, `Bwd Avg Packets/Bulk`, `Bwd Avg Bulk Rate`): Constant `0.0` across all samples.

### 3.5 Target Label Separation
Labels are extracted into separate arrays and decoupled from the feature matrix:
- `y_raw`: String label specifying exact attack type (e.g., `BENIGN`, `DoS Hulk`, `PortScan`, `DDoS`).
- `y_multiclass`: Integer class ID ($0$ to $14$, with $0 = \text{BENIGN}$).
- `y_binary`: Binary anomaly label ($0 = \text{BENIGN}$, $1 = \text{Anomaly/Attack}$).

### 3.6 StandardScaler Preprocessing
- Features are normalized via Z-score standardization:
  $$z = \frac{x - \mu}{\sigma}$$
- Feature matrices are stored in single-precision IEEE 754 float (`float32`) for optimal GPU computing performance.
- Fitted scaler parameters ($\mu$ and $\sigma$) are saved in metadata for reproducible inference.

### 3.7 Reproducible Experimental Subsets
Controlled stratified subsets are generated using a fixed random seed (`seed = 42`):
- `10k` ($N = 10,000$)
- `25k` ($N = 25,000$)
- `100k` ($N = 100,000$)
- `250k` ($N = 250,000$)
- `500k` ($N = 500,000$)
- `1m` ($N = 1,000,000$)
- `full` ($N = 2,520,798$)

## 5. Usage Commands

Run dataset inspection:
```powershell
python preprocessing/inspect_dataset.py
```

Run complete preprocessing pipeline:
```powershell
python preprocessing/prepare_dataset.py --seed 42 --raw-dir data/raw --output-dir data/processed
```
